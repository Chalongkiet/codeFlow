## 🌟 ภาพรวมระบบ (Overview)

**CodeFlow: Logic Animator** คือเกม Interactive Edutainment ที่ให้ผู้เล่นสวมบทบาทเป็น **System Engineer** ผู้ออกแบบอัลกอริทึมควบคุมระบบอัตโนมัติ 5 ประเภท ตั้งแต่ฟาร์ม IoT ไปจนถึงระบบความปลอดภัยไซเบอร์

จุดเด่นที่แตกต่างจากเกมเรียงบล็อกทั่วไปคือ **ระบบจำลองผลลัพธ์แบบเรียลไทม์ (Live Simulation)** — เมื่อผู้เล่นกด RUN ระบบจะรันคำสั่งทีละขั้นพร้อมแสดงภาพเคลื่อนไหวของสิ่งที่เกิดขึ้นจริงในระบบ ถ้าเรียงถูกจะเห็นผักเติบโต โดรนส่งของสำเร็จ รถถึงที่หมาย แต่ถ้าเรียงผิดจะเห็นน้ำท่วมแปลงผัก โดรนชนเครน หรือแฮกเกอร์เดินเข้าประตูหน้า ทำให้ผู้เล่นเข้าใจ **เหตุและผลของลำดับคำสั่ง** ได้ทันทีโดยไม่ต้องอ่านคำอธิบาย

รองรับ **Dual-Control System** เล่นได้ทั้งเมาส์/จอสัมผัส และ **AI Hand Tracking แบบเต็มจอ** ผ่านกล้องเว็บแคม เหมาะสำหรับบูธนิทรรศการที่มีผู้เล่นหมุนเวียนตลอดวัน

* **ที่ตั้งไฟล์:** `codeflow-logic-animator.html` (Single File — ไม่ต้องติดตั้งอะไรเพิ่ม)
* **เสาหลักที่เกี่ยวข้อง:** ครบทั้ง 4 เสาหลัก
  * เสาหลักที่ 1 & 2 — *Hands-on & Agile: Computational Thinking, Debugging, Algorithm Design*
  * เสาหลักที่ 3 — *Modern Tech Ecosystem: IoT, Cloud, Cyber Security, Robotics*
  * เสาหลักที่ 4 — *Green IT & Smart Agriculture: ระบบเกษตรอัจฉริยะและโลจิสติกส์*

## 1. 🌱 World 1: IoT Smart Farm

### 🎯 คอนเซ็ปต์

จำลองโรงเรือนอัจฉริยะที่ควบคุมด้วยบอร์ด ESP32 ผู้เล่นต้องเขียนตรรกะให้ระบบอ่านค่าเซนเซอร์ ตัดสินใจตามเงื่อนไข และสั่งงานอุปกรณ์ให้ถูกลำดับ

### 🕹️ ระบบเกม

* **บล็อกคำสั่ง:** `อ่านค่าความชื้นดิน` · `ถ้า ความชื้น < 38%` · `เปิดวาล์วน้ำ` · `หน่วงเวลา` · `ปิดวาล์วน้ำ` · `ส่งข้อมูลขึ้น Cloud`
* **ค่าที่สุ่ม:** เกณฑ์ความชื้น, ค่า EC, ความเข้มแสง, อุณหภูมิ, ระยะเวลารดน้ำ, ชนิดพืชที่ปลูก
* **กฎประจำโลก:** ต้องอ่านค่าเซนเซอร์ก่อนตรวจเงื่อนไขเสมอ และทุกอุปกรณ์ที่สั่ง "เปิด" ต้องมีคำสั่ง "ปิด" ก่อนจบโปรแกรม
* **Simulation:** แปลงผัก 4 ต้นที่เติบโตหรือเหี่ยวตามค่าความชื้นจริง มาตรวัด Soil Moisture / Temperature / Crop Health แบบเรียลไทม์
* **บทเรียนจากความผิดพลาด:** เปิดวาล์วก่อนตรวจเงื่อนไข → น้ำท่วมแปลง ผักลอยไปกับสายน้ำ · ลืมปิดวาล์ว → รากเน่า

## 2. 🚁 World 2: Delivery Drone

### 🎯 คอนเซ็ปต์

ควบคุมโดรนขนส่งให้บินจากฐานไปยังจุดหมาย พร้อมหลบสิ่งกีดขวางระหว่างทางและปล่อยพัสดุอย่างปลอดภัย

### 🕹️ ระบบเกม

* **บล็อกคำสั่ง:** `สแกนพิกัด` · `ตรวจสอบแบตเตอรี่` · `บินขึ้น 15 เมตร` · `ตรวจจับสิ่งกีดขวางด้วย LiDAR` · `ไต่ระดับ/ลดระดับหลบ` · `ปล่อยพัสดุ` · `บินกลับฐาน (RTL)`
* **กับดักเชิงตรรกะ:** ทิศทางการหลบขึ้นอยู่กับสิ่งกีดขวางที่สุ่มขึ้นมาในแต่ละรอบ — เครนยื่นจากด้านบนต้อง **ลอดใต้** แต่รถบรรทุกสูงด้านล่างต้อง **ไต่ข้าม** ผู้เล่นจึงต้องดูภาพจำลอง ท่องคำตอบไม่ได้
* **กฎประจำโลก:** โดรนต้องบินขึ้นก่อนจึงเคลื่อนที่ได้ และต้องอยู่เหนือจุดวางแล้วเท่านั้นจึงปล่อยพัสดุได้
* **Simulation:** โดรนใบพัดหมุน มาตรวัดแบตเตอรี่และระดับความสูง เมืองแบบ Parallax และลานจอดปลายทางที่กะพริบรอรับ
* **บทเรียนจากความผิดพลาด:** ปล่อยพัสดุกลางอากาศ → ของแตกกระจาย · หลบผิดทิศ → ชนเต็มแรงพร้อมควันขึ้น

## 3. 🔐 World 3: Cyber Security

### 🎯 คอนเซ็ปต์

ออกแบบกระบวนการยืนยันตัวตนและตอบสนองเหตุการณ์ความปลอดภัย สอนหลัก **Defense in Depth** ว่าลำดับการตรวจสอบสำคัญกว่าจำนวนมาตรการ

### 🕹️ ระบบเกม

* **บล็อกคำสั่ง:** `รับ Username/Password` · `เข้ารหัสรหัสผ่าน (Hash + Salt)` · `ตรวจสอบกับฐานข้อมูล` · `สร้างและส่ง OTP` · `ตรวจสอบ OTP` · `อนุมัติเข้าสู่ระบบ` · `บันทึก Log`
* **บล็อกลวงเชิงการศึกษา:** `เก็บรหัสผ่านเป็นข้อความธรรมดา` · `ปิดไฟร์วอลล์ชั่วคราว` · `ข้ามขั้นตอน OTP` · `ให้สิทธิ์ Admin แก่ผู้ใช้` — บล็อกเหล่านี้ดูเหมือนจะทำให้งานเสร็จเร็วขึ้น แต่คือช่องโหว่ที่พบจริงในระบบที่ถูกเจาะ
* **กฎประจำโลก:** ห้ามให้สิทธิ์ก่อนยืนยันตัวตนครบทุกชั้น และห้ามเก็บหรือส่งข้อมูลลับแบบไม่เข้ารหัส
* **Simulation:** โล่ป้องกัน 3 ชั้น (AUTH / VERIFY / SESSION) ที่ติดสว่างทีละชั้น แพ็กเก็ตข้อมูลวิ่งระหว่างผู้ใช้กับเซิร์ฟเวอร์ และจอกลิตช์สีแดงพร้อมสัญลักษณ์กะโหลกเมื่อระบบถูกเจาะ

## 4. 🍳 World 4: Robo Kitchen

### 🎯 คอนเซ็ปต์

ครัวหุ่นยนต์อัตโนมัติ สอนแนวคิด **Order Dependency** ผ่านสิ่งที่ทุกคนคุ้นเคย — การทำอาหารที่สลับขั้นตอนไม่ได้

### 🕹️ ระบบเกม

* **3 สูตรสุ่ม:** ผัดกะเพรา (เตาและกระทะ) · อบขนมปัง (เตาอบและการพักแป้ง) · ชงลาเต้ (เครื่องเอสเพรสโซ)
* **ค่าที่สุ่ม:** ปริมาณแป้ง, เวลานวด, เวลาพักแป้ง, อุณหภูมิเตาอบ, เวลาอบ, ปริมาณกาแฟที่บด, เวลาสกัด, อุณหภูมิสตีมนม, ชนิดเนื้อสัตว์
* **กฎประจำโลก:** ต้องเตรียมอุปกรณ์ให้พร้อมก่อนใส่วัตถุดิบ และต้องดับความร้อนก่อนจัดเสิร์ฟทุกครั้ง
* **Simulation:** เปลวไฟที่สูงตามระดับความร้อน วัตถุดิบตกลงกระทะทีละอย่าง ไอน้ำลอยขึ้น เตาอบที่เรืองแสงตามอุณหภูมิ และแก้วกาแฟที่ค่อย ๆ เต็ม
* **บทเรียนจากความผิดพลาด:** ล็อกด้ามชงก่อนอัดผงกาแฟ → น้ำทะลุเป็นรู · เข้าอบทั้งที่เตายังไม่ร้อน → ขนมดิบกลางใน · ใส่น้ำแข็งลงกระทะร้อน → ไอน้ำระเบิด

## 5. 🚗 World 5: Route Finder

### 🎯 คอนเซ็ปต์

นำรถขนส่งอัตโนมัติจากจุดสตาร์ทไปถึงปลายทางอย่างปลอดภัย ฝึกการแปลงเส้นทางบนแผนที่ให้เป็นชุดคำสั่ง และเข้าใจเรื่อง **ทิศทางสัมพัทธ์ (Relative Direction)**

### 🕹️ ระบบเกม

* **แผนที่สุ่มใหม่ทุกครั้ง:** ระบบสร้างเส้นทางบนกริด 7×5 พร้อมตึก ต้นไม้ กรวยจราจร และสัญญาณไฟแดง แล้วแปลงเส้นทางนั้นเป็นชุดคำสั่งที่ถูกต้อง
* **บล็อกคำสั่ง:** `สตาร์ทเครื่องยนต์` · `ขับตรงไป 3 ช่อง` · `เลี้ยวซ้าย` · `เลี้ยวขวา` · `หยุดรอสัญญาณไฟแดง` · `จอดที่จุดหมายอย่างปลอดภัย`
* **จุดที่ท้าทายที่สุด:** ซ้าย-ขวาอิงจาก **ทิศที่หัวรถหันอยู่** ไม่ใช่ทิศบนจอ พอเลี้ยวขึ้นเหนือแล้วความหมายของซ้ายขวาจะกลับด้าน และคำสั่งเลี้ยวจะหมุนหัวรถอย่างเดียว รถยังไม่ขยับ ต้องตามด้วยคำสั่งขับตรงเสมอ
* **Simulation:** รถหมุนตามทิศจริง ไฟหน้าส่องสว่าง เส้นถนนเรืองแสงไหลตามเส้นทาง และแอนิเมชันชนตึกพร้อมควันเมื่อคำนวณระยะผิด

## 📋 ระบบสื่อสารโจทย์ (Mission Briefing)

โจทย์ทุกข้อเขียนในรูปแบบ **ข้อกำหนดของระบบ (System Requirements)** ที่บอกทั้ง *ต้องทำอะไร* และ *ทำไมต้องเป็นลำดับนั้น* ไม่ใช่แค่รายการขั้นตอน

* **ข้อกำหนดปรับตามด่าน** — ข้อกำหนดแต่ละข้อผูกกับขั้นตอนจริงในด่านนั้น ถ้าระดับความยากตัดขั้นตอนใดออก ข้อกำหนดของขั้นนั้นจะไม่แสดง โจทย์กับจำนวนช่องจึงตรงกันเสมอ
* **กล่องกฎประจำโลก** — สรุปกติกาที่ห้ามละเมิดของโลกนั้น แสดงเป็นแถบสีเหลืองใต้ข้อกำหนด
* **แถบข้อมูลด่าน** — บอกตรง ๆ ว่า `อัลกอริทึม 7 ขั้น · คลัง 10 บล็อก · มีบล็อกลวง 3 ใบ` ผู้เล่นจะได้รู้ว่าต้องเหลือบล็อกทิ้งไว้ ไม่ใช่ใช้ให้หมด
* **คำอธิบายใต้ทุกบล็อก** — บล็อกทั้ง 101 ชนิดมีคำอธิบายว่าคำสั่งนั้นทำอะไร เช่น `เลี้ยวซ้าย` → *หมุนหัวรถไปทางซ้าย 90° — รถยังไม่เคลื่อนที่* และ `ถ้า ความชื้น < 40%` → *เงื่อนไขจริง → ทำคำสั่งถัดไป · เงื่อนไขเท็จ → จบโปรแกรม*
  คำอธิบายของ **บล็อกลวงเขียนด้วยน้ำเสียงเป็นกลางเท่ากับบล็อกจริง** เพื่อไม่ให้ผู้เล่นเดาคำตอบจากโทนของข้อความแทนการใช้ตรรกะ

## 🛡️ ระบบป้องกันการโกงและการจำคำตอบ (Anti-Cheat System)

ระบบนี้คือหัวใจของเกม เพราะในงานนิทรรศการผู้เล่นคนหลังมักได้เปรียบจากการยืนดูคนหน้าเล่น **เกมนี้ไม่มีชุดโจทย์สำเร็จรูปเก็บไว้เลย ทุกภารกิจถูกสร้างสดจากตัวสุ่มตอนกดเริ่ม**

| กลไก                           | รายละเอียด                                                                                                                                                                                                                                                                                                         |
| ---------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Procedural Generation**    | สุ่มเทมเพลตภารกิจ แล้วสุ่มค่าพารามิเตอร์ทั้งหมดใหม่ทุกครั้ง (เกณฑ์เซนเซอร์, ระยะทาง, อุณหภูมิ, เวลา, ขนาดคีย์เข้ารหัส, เส้นทางบนแผนที่)                                                             |
| **Dynamic Algorithm Length** | ความยาวอัลกอริทึมเปลี่ยนตามระดับความยาก (5 / 7 / 9 / 11 ขั้น) โดยเลือกขั้นตอนเสริมเข้ามาเป็นชุดที่ยังคงความถูกต้องเชิงตรรกะ                                                                                          |
| **Parameter Trap**           | สร้างบล็อกลวงที่มีค่าใกล้เคียงของจริง เช่น`ถ้า ความชื้น < 38%` คู่กับ `< 45%` บังคับให้อ่านโจทย์ ไม่ใช่จำรูปทรงบล็อก                                                                                                      |
| **Context-Dependent Answer** | คำตอบบางข้อขึ้นกับภาพจำลองที่สุ่มขึ้นมา เช่น ทิศทางหลบสิ่งกีดขวางของโดรน และเส้นทางของรถส่งของ                                                                                                                                    |
| **Educational Decoy**        | บล็อกลวงที่เป็นการปฏิบัติผิดหลักวิชาชีพจริง เช่น`ข้ามขั้นตอน OTP`, `เปิดฝาเตาอบระหว่างอบ`, `ฝ่าสัญญาณไฟแดง`                                                                                                                |
| **Fresh Puzzle on Timeout**  | หมดเวลาแล้วได้โจทย์ใหม่ ไม่ใช่โจทย์เดิม ปิดช่องการลองซ้ำจนจำได้                                                                                                                                                                                                 |
| **Reproducible Seed**        | ช่อง SEED ในหน้าเมนู — ปล่อยว่างทุกคนได้โจทย์คนละชุด แต่ถ้ากรรมการต้องการให้ผู้แข่งทุกคนเจอชุดเดียวกันเพื่อความยุติธรรม ใส่ SEED เดียวกันจะได้ลำดับภารกิจเดิมทุกประการ |

> **ผลการทดสอบ:** รัน generator กว่า 8,000 ครั้งครอบคลุมทั้ง 5 โลก 4 ระดับความยาก ไม่พบข้อผิดพลาด · ตรวจเส้นทางในโลกที่ 5 อีก 2,000 ครั้งว่าเดินตามคำสั่งแล้วถึงธงเป้าหมายพอดีทุกครั้ง · จำลองการวางบล็อกจนครบ 33,064 ขั้น ผ่านการตรวจคำตอบทั้งหมดโดยไม่มีข้อผิดพลาด

## 🕹️ Core Gameplay Loop

1. **Mission Brief** — ระบบแสดงสถานการณ์ ข้อกำหนด กฎประจำโลก และ Mission ID เฉพาะของรอบนั้น
2. **Flowchart Drag & Drop** — คีบบล็อกจากคลังมาเรียงในช่อง Flowchart ด้วยการจีบนิ้วหรือลากเมาส์
3. **Step-by-Step Execution** — กด RUN แล้วระบบไฮไลต์บล็อกที่กำลังทำงานทีละขั้น พร้อมเล่นแอนิเมชันผลลัพธ์ในจอจำลองทันที
4. **Smart Lock** — ขั้นที่ถูก บล็อกเปลี่ยนเป็นสีเขียว เล่นเสียง Chime และ **ล็อกติดกับช่อง** แก้ไม่ได้อีก
5. **Partial Reset** — ขั้นที่ผิด แสดงแอนิเมชันความเสียหายเชิงขบขัน แล้ว **เฉพาะบล็อกที่ผิด** เด้งกลับคลัง ผู้เล่นแก้เฉพาะจุดนั้นแล้วกด RUN ต่อได้เลย ไม่ต้องเริ่มใหม่ทั้งด่าน

## 🎓 คุณค่าการเรียนรู้ (Computational Thinking)

* **Decomposition** — ย่อยระบบใหญ่ เช่น "ทำระบบล็อกอินสองชั้น" ให้เป็นขั้นตอนย่อยที่รันได้จริง
* **Pattern Recognition** — เห็นรูปแบบซ้ำข้ามโลก เช่น *อ่านค่า → ตรวจเงื่อนไข → สั่งงาน → บันทึกผล* ใช้ได้ทั้งกับฟาร์ม โดรน และครัว
* **Abstraction** — แยกแยะว่าอะไรคือขั้นตอนที่จำเป็น และอะไรคือบล็อกลวงที่ดูน่าใช้แต่ไม่เกี่ยวกับโจทย์
* **Algorithm Design** — วางลำดับเงื่อนไขก่อน-หลังอย่างเป็นระบบ และเข้าใจว่าลำดับผิดคือโปรแกรมผิด แม้จะใช้คำสั่งครบทุกตัว
* **Debugging** — วิเคราะห์สาเหตุจากแอนิเมชันความผิดพลาดแล้วแก้ตรงจุด ระบบ Smart Lock ช่วยจำกัดขอบเขตปัญหาให้เหลือเฉพาะขั้นที่พังจริง

## 💻 เทคโนโลยีที่ใช้ในการพัฒนา (Tech Stack)

* **Frontend Core:** HTML5, CSS3 (Industrial HMI / SCADA Terminal Design System), JavaScript (ES6+) — รวมทุกอย่างในไฟล์เดียว ไม่มี Build Step
* **Rendering Engine:** HTML5 Canvas 2D พร้อม Render Loop แบบ Delta-Time, ระบบ Particle, Screen Shake และ Floating Text
* **Execution Engine:** State Machine แบบขั้นต่อขั้นที่ต่อกันด้วย `setTimeout` แทนลูปที่มี `await` ค้างอยู่ข้างใน เพื่อไม่ให้ตัวเฝ้าระวัง infinite loop ของเบราว์เซอร์เข้าใจผิดว่าโปรแกรมค้าง
* **Procedural Generation:** Mulberry32 Seeded PRNG — สุ่มแบบทำซ้ำได้จาก Seed เดียวกัน (Deterministic)
* **Computer Vision & AI Tracking:** Google MediaPipe Hands (โหลดผ่าน CDN แบบ Lazy Load เมื่อผู้ใช้อนุญาตกล้องแล้วเท่านั้น) พร้อม Fallback อัตโนมัติกลับสู่โหมดเมาส์
* **Audio Synthesis:** Web Audio API สร้างเสียง Chime, Error, Combo และ Fanfare แบบเรียลไทม์ ไม่ต้องพึ่งไฟล์เสียงภายนอก
* **Error Resilience:** ดักจับ `unhandledrejection` และ error ระดับหน้า พร้อมห่อ Render Loop ด้วย try-catch เพื่อไม่ให้ข้อผิดพลาดจุดเดียวทำให้ทั้งเกมหยุดทำงาน
* **Responsive Architecture:** CSS Grid / Flexbox รองรับจอนิทรรศการแนวนอน, PC/Notebook และ iPad/Tablet พร้อมรองรับ `prefers-reduced-motion`
